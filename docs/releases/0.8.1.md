# Workspace 0.8.1

Workspace 0.8.1 is the final legacy containment release. It does not include
the in-flight work-fold product changes and it never points at a work-fold
update feed.

## Coexistence safety

- `.work-fold/`, `.workspace/`, and `.pi/` are hidden from Files and Search and
  excluded from History, Chat attachments, Checks, restricted-app file grants,
  restricted-app source packages, and generated App Releases.
- Reserved metadata matching is case-insensitive on every platform, including
  `.WORK-FOLD` and `.WORKSPACE` on Windows.
- Deleting a legacy managed Space that contains `.work-fold/` now removes the
  Workspace registration and machine-local state while preserving the entire
  managed folder. The confirmation and result copy disclose that outcome.
- The removal guard is rechecked after the managed folder is atomically claimed,
  closing the race between approval and recursive deletion.

This release does not import, migrate, modify, or delete work-fold state. After
the three current testers install 0.8.1, the legacy source and Windows/macOS
release feeds are frozen. Existing release downloads remain public, and no
work-fold artifact will ever be published to either legacy feed.
